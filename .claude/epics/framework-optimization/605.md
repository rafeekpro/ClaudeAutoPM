# [refactor][core] Framework-wide optimization: prompts, token usage, code quality, security, tests

Epic-level refactoring pass. Full specification: https://github.com/rafeekpro/ClaudeAutoPM/issues/605

## Goal

Optimize code quality, improve AI prompts, reduce token consumption, harden security, eliminate latent bugs, and strengthen test coverage across ClaudeAutoPM.

## Two layers (do not conflate)

1. **Framework payload (the product — priority)**: `autopm/.claude/` + `packages/plugin-*/` — installed into user projects by `autopm install`. Optimizations here have multiplied impact.
2. **This repo's own config (secondary)**: root `.claude/` — dogfooding setup, refreshed as a consumer of the improved framework.

Plus installer/CLI machinery: `bin/`, `lib/`.

## Plan (from issue)

1. **Audit phase** ← current: inventory duplicated prompts/scripts, measure token counts per distributed command, lint/static-analysis baseline
2. **Decompose into sub-issues** per area — framework payload first, repo config last
3. **TDD per sub-issue**
4. **Verification phase**: test matrix, token before/after report, security checklist, e2e `autopm install`

## Acceptance Criteria

See issue #605 — prompts dedupe, ≥20% token reduction on top-10 commands, shell-lib single source of truth (plugin-core), security hardening, coverage thresholds met.
