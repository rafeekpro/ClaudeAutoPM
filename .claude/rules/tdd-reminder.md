# TDD Reminder

This project follows Test-Driven Development. Before ANY coding work begins,
follow the RED-GREEN-REFACTOR cycle:

1. **RED Phase**: Write a failing test that describes the desired behavior
2. **GREEN Phase**: Write the minimum code to make the test pass
3. **REFACTOR Phase**: Clean up the code while keeping tests green

Non-negotiable:

- No implementation without a failing test first
- Tests define the specification — write them from requirements, not from code
- Keep the cycle short; commit at RED and GREEN boundaries
